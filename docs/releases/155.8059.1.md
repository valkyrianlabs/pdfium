## Install

```sh
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://apt.vaulthalla.sh/pubkey.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/vaulthalla.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/vaulthalla.gpg] https://apt.vaulthalla.sh stable main" \
  | sudo tee /etc/apt/sources.list.d/vaulthalla.list
sudo apt update && sudo apt install libpdfium-dev     # pulls in libpdfium8059
pkg-config --cflags --libs pdfium                      # -I/usr/include/pdfium -lpdfium
```

A host that still has the legacy `libpdfium-dev 20250629-1` needs
`sudo apt install --allow-downgrades libpdfium-dev=155.8059.1-1` once.

## Notes

- `v155.8059.0` was tagged first and **never published**: its publish job's
  `vlr checksums --verify` refused an artifact set that contained a test report written after
  checksumming. Fixed in `ef188e1` (reports go to `build/package-tests/`, artifacts are
  re-verified after the package tests) and released as `155.8059.1`. Nothing else changed.
- The legacy packages remain off apt.vaulthalla.sh; nothing was published to apt.valkyrianlabs.com.

## Limitations

- amd64 only; arm64 is planned (`docs/CI.md`, "ARM64").
- No JavaScript, XFA forms or Skia rendering in this configuration.
- Vaulthalla must be rebuilt against `libpdfium-dev` to depend on `libpdfium8059`.
